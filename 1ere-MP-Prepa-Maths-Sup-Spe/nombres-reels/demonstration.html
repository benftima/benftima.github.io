Démonstration Générale & Application Pratique

Par Ben Ftima Mohamed — Tél: +216 21 409 061

Ce document présente la preuve algébrique générale permettant de transformer tout développement décimal périodique en fraction rationnelle, illustrée ligne par ligne par un exemple concret basé sur le nombre x = 5,2343434... (où la période est 34 de longueur p=2, et le décalage après la virgule est 2 de longueur d=1).

Étape 1 : Amener la virgule juste avant la période
Ligne Générale : On multiplie x par 10d pour déplacer la virgule de d rangs vers la droite.
10d · x = Partie avant la période + 0,période...
Application à l'exemple : On multiplie par 101 = 10 pour sauter le chiffre 2.
10x = 52,343434...
Étape 2 : Amener la virgule juste après la première période
Ligne Générale : On multiplie x par 10d+p pour déplacer la virgule après la première période.
10d+p · x = Tout le nombre sans virgule + 0,période...
Application à l'exemple : On multiplie par 101+2 = 103 = 1000 pour sauter le 2, le 3 et le 4.
1000x = 5234,343434...
Étape 3 : Poser la soustraction pour éliminer l'infini
Ligne Générale : On soustrait la première égalité à la deuxième pour annuler la partie infinie 0,période...
10d+p · x - 10d · x = Tout le nombre - Partie avant la période
Application à l'exemple : On soustrait 10x à 1000x.
1000x - 10x = 5234,3434... - 52,3434...
Étape 4 : Calculer les deux membres
Ligne Générale : On factorise à gauche et on effectue la soustraction entière à droite.
10d(10p - 1) · x = Résultat Entier
Application à l'exemple : On effectue les calculs numériques.
990x = 5182
Étape 5 : Isoler x sous forme de fraction finie
Ligne Générale : On divise pour obtenir la formule de la fraction générale.
x = (Tout le nombre - Partie avant la période) / [10d(10p - 1)]
Application à l'exemple : On extrait la fraction finale et on la simplifie.
x = 5182 / 990 = 2591 / 495
