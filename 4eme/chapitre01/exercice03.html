Exercice 3 — Valeur absolue

Une étude de fonction pour comprendre le passage d'une expression avec valeur absolue à une fonction définie par morceaux.

EXERCICE 3 · RÉVISION

Énoncé

On considère la fonction \(f\) définie sur \(\mathbb R\) par :

\[\boxed{f(x)=|x^2-4|}\]

1. Déterminer le domaine de définition de \(f\).

2. Déterminer les valeurs de \(x\) pour lesquelles \(x^2-4=0\).

3. Écrire \(f(x)\) sans valeur absolue sur chacun des intervalles déterminés.

4. Étudier la continuité de \(f\) sur \(\mathbb R\).

5. Calculer \(f'(x)\) sur les intervalles où \(f\) est dérivable.

6. Étudier le signe de \(f'(x)\).

7. Dresser le tableau de variations de \(f\).

8. Déterminer les extrema de \(f\).

9. Déterminer l'image de \(f\).

10. Représenter graphiquement la fonction.

Objectif : comprendre comment la valeur absolue conduit à une étude par morceaux, puis utiliser la dérivée pour déterminer les variations.

Le chemin de l'étude

Avant de dériver, il faut déterminer le signe de \(x^2-4\).

Objectif

  • utiliser la définition de la valeur absolue ;
  • étudier le signe de \(x^2-4\) ;
  • écrire une fonction par morceaux ;
  • étudier sa dérivée et ses variations.

Prérequis

Connaissances nécessaires
  • \(|u|=\begin{cases}u&u\ge0\\-u&u<0\end{cases}\)
  • Factorisation : \(x^2-4=(x-2)(x+2)\).
  • Signe d'un produit.
  • Dérivée de \(x^2\).
La valeur absolue

On utilise :

\[ |u|=\begin{cases}u&\text{si }u\ge0,\\-u&\text{si }u<0.\end{cases} \]

Ici \(u(x)=x^2-4\).

1. Domaine de définition

La valeur absolue est définie pour tout réel.

Donc : \[\boxed{D_f=\mathbb R}.\]

2. Valeurs importantes

\[ x^2-4=(x-2)(x+2)=0 \]

\[\boxed{x=-2\quad\text{ou}\quad x=2}\]

Ces valeurs déterminent les trois intervalles \(]-\infty,-2[\), \(]-2,2[\) et \(]2,+\infty[\).

3. Écrire \(f\) sans valeur absolue

\(x\)\(-\infty\)\(-2\)\(2\)\(+\infty\)
\(x^2-4\)+0−0+
\[ \boxed{f(x)=\begin{cases} x^2-4&\text{si }x\le-2,\\ 4-x^2&\text{si }-2\le x\le2,\\ x^2-4&\text{si }x\ge2. \end{cases}} \]
Idée essentielle : lorsque \(u(x)<0\), \(|u(x)|=-u(x)\).

4. Continuité et dérivée

Continuité : \(x\mapsto x^2-4\) et la valeur absolue sont continues sur \(\mathbb R\). Donc \(f\) est continue sur \(\mathbb R\).

Dérivée par morceaux

Pour \(x<-2\) ou \(x>2\) :

\[\boxed{f'(x)=2x}.\]

Pour \(-2

\[\boxed{f'(x)=-2x}.\]
Attention : aux points \(-2\) et \(2\), on compare les dérivées à gauche et à droite.

5. Limites

\[\boxed{\lim_{x\to-\infty}f(x)=+\infty,\qquad\lim_{x\to+\infty}f(x)=+\infty}.\]

6. Signe de \(f'(x)\)

Intervalle\(]-\infty,-2[\)\(]-2,0[\)\(]0,2[\)\(]2,+\infty[\)
\(f'(x)\)\(2x<0\)\(-2x>0\)\(-2x<0\)\(2x>0\)
\[ f'<0\text{ sur }]-\infty,-2[\cup]0,2[,\qquad f'>0\text{ sur }]-2,0[\cup]2,+\infty[. \]

7. Tableau de variations

\(x\)\(-\infty\)\(-2\)02\(+\infty\)
\(f'(x)\)−+0−+
\(f(x)\)+\infty↘0↗4↘0↗+\infty

8. Extrema

  • minimum global : \(\boxed{0}\), atteint pour \(x=-2\) et \(x=2\) ;
  • maximum local : \(\boxed{4}\), atteint pour \(x=0\) ;
  • pas de maximum global car \(f(x)\to+\infty\).

9. Image de \(f\)

Comme \(f(x)=|x^2-4|\), on a \(f(x)\ge0\), et toutes les valeurs positives sont atteintes.

Image :
\[\boxed{\operatorname{Im}(f)=[0,+\infty[}.\]

10. Représentation graphique

La courbe est formée de trois morceaux de paraboles.

À retenir

Pour une fonction avec valeur absolue :
  1. Repérer les zéros de \(u(x)\).
  2. Étudier le signe de \(u(x)\).
  3. Supprimer la valeur absolue par morceaux.
  4. Étudier chaque morceau.
  5. Réunir les résultats.

💡 Commentaire pédagogique

La valeur absolue impose de commencer par étudier le signe de ce qui se trouve à l'intérieur.

Ici, les deux valeurs \(-2\) et \(2\) permettent de découper la droite réelle et d'écrire la fonction par morceaux.
