Correction détaillée — Exercice N° 2

On considère les matrices \[ A= \begin{pmatrix} 1&1&1\\ 2&4&5\\ 5&6&8 \end{pmatrix} \qquad\text{et}\qquad B= \begin{pmatrix} 2&-2&1\\ 9&3&-3\\ -8&-1&2 \end{pmatrix}. \]

Idée générale de l'exercice : on commence par montrer que \(A\) est inversible, puis on utilise le produit \(AB\) pour obtenir rapidement \(A^{-1}\). Cette matrice inverse permet ensuite de résoudre le système \((S)\). Enfin, on reconnaît que le problème de couture se traduit exactement par ce même système.

1. Déterminant et inversibilité de \(A\)

a. Calcul de \(\det(A)\)

On a : \[ \det(A)= \begin{vmatrix} 1&1&1\\ 2&4&5\\ 5&6&8 \end{vmatrix}. \]

On développe le déterminant suivant la première ligne. Le signe des trois termes est successivement \(+\), \(-\), \(+\) :

\[ \det(A) = 1 \begin{vmatrix} 4&5\\ 6&8 \end{vmatrix} - 1 \begin{vmatrix} 2&5\\ 5&8 \end{vmatrix} + 1 \begin{vmatrix} 2&4\\ 5&6 \end{vmatrix}. \]

Calculons séparément les déterminants d'ordre \(2\).

\[ \begin{vmatrix} 4&5\\ 6&8 \end{vmatrix} =4\times8-5\times6 =32-30 =2. \]
\[ \begin{vmatrix} 2&5\\ 5&8 \end{vmatrix} =2\times8-5\times5 =16-25 =-9. \]
\[ \begin{vmatrix} 2&4\\ 5&6 \end{vmatrix} =2\times6-4\times5 =12-20 =-8. \]

Donc :

\[ \det(A)=2-(-9)+(-8) \] \[ \det(A)=2+9-8 \] \[ \boxed{\det(A)=3}. \]

b. Déduire que \(A\) est inversible

Une matrice carrée est inversible si et seulement si son déterminant est non nul.

\[ \det(A)=3\neq0. \]

Par conséquent :

\[ \boxed{A\text{ est inversible}.} \]

2. Calcul de \(AB\) et détermination de \(A^{-1}\)

a. Calcul de \(AB\)

Pour multiplier deux matrices, on utilise la règle « ligne de la première matrice × colonne de la deuxième ».

Ainsi :

\[ AB= \begin{pmatrix} 1&1&1\\ 2&4&5\\ 5&6&8 \end{pmatrix} \begin{pmatrix} 2&-2&1\\ 9&3&-3\\ -8&-1&2 \end{pmatrix}. \]

Première ligne

Première colonne :

\[ 1(2)+1(9)+1(-8) =2+9-8 =3. \]

Deuxième colonne :

\[ 1(-2)+1(3)+1(-1) =-2+3-1 =0. \]

Troisième colonne :

\[ 1(1)+1(-3)+1(2) =1-3+2 =0. \]

La première ligne du produit est donc :

\[ (3,\;0,\;0). \]

Deuxième ligne

Première colonne :

\[ 2(2)+4(9)+5(-8) =4+36-40 =0. \]

Deuxième colonne :

\[ 2(-2)+4(3)+5(-1) =-4+12-5 =3. \]

Troisième colonne :

\[ 2(1)+4(-3)+5(2) =2-12+10 =0. \]

La deuxième ligne est donc :

\[ (0,\;3,\;0). \]

Troisième ligne

Première colonne :

\[ 5(2)+6(9)+8(-8) =10+54-64 =0. \]

Deuxième colonne :

\[ 5(-2)+6(3)+8(-1) =-10+18-8 =0. \]

Troisième colonne :

\[ 5(1)+6(-3)+8(2) =5-18+16 =3. \]

La troisième ligne est donc :

\[ (0,\;0,\;3). \]

Finalement :

\[ \boxed{ AB= \begin{pmatrix} 3&0&0\\ 0&3&0\\ 0&0&3 \end{pmatrix}} \]

Or :

\[ I_3= \begin{pmatrix} 1&0&0\\ 0&1&0\\ 0&0&1 \end{pmatrix}. \]

Donc :

\[ \boxed{AB=3I_3}. \]

b. Déduire \(A^{-1}\)

Nous avons obtenu : \[ AB=3I_3. \]

On écrit \(3I_3=I_3\times3\), puis on divise par \(3\) :

\[ A\left(\frac13B\right)=I_3. \]

Par définition de la matrice inverse, cela donne :

\[ \boxed{A^{-1}=\frac13B}. \]

En remplaçant \(B\) :

\[ A^{-1} = \frac13 \begin{pmatrix} 2&-2&1\\ 9&3&-3\\ -8&-1&2 \end{pmatrix}. \] Donc :

\[ \boxed{ A^{-1} = \begin{pmatrix} \frac23&-\frac23&\frac13\\ 3&1&-1\\ -\frac83&-\frac13&\frac23 \end{pmatrix}} \]
Astuce : le sujet a choisi la matrice \(B\) de façon à obtenir \[ AB=3I_3. \] Il est donc inutile de calculer les cofacteurs de \(A\) pour trouver son inverse.

3. Résolution du système \((S)\)

Le système est :

\[ (S)\quad \left\{ \begin{aligned} x+y+z&=400\\ 2x+4y+5z&=1420\\ 5x+6y+8z&=2460. \end{aligned} \right. \]

a. Écriture matricielle

On reconnaît exactement la matrice \(A\) dans les coefficients des inconnues.

On pose :

\[ X= \begin{pmatrix} x\\y\\z \end{pmatrix}, \qquad C= \begin{pmatrix} 400\\1420\\2460 \end{pmatrix}. \]

Le système devient :

\[ \boxed{ AX=C } \] c'est-à-dire : \[ \boxed{ \begin{pmatrix} 1&1&1\\ 2&4&5\\ 5&6&8 \end{pmatrix} \begin{pmatrix} x\\y\\z \end{pmatrix} = \begin{pmatrix} 400\\1420\\2460 \end{pmatrix}. } \]

b. Déduire la solution

Puisque \(A\) est inversible, on peut multiplier à gauche par \(A^{-1}\) :

\[ A^{-1}AX=A^{-1}C. \]

Or :

\[ A^{-1}A=I_3. \] Donc : \[ X=A^{-1}C. \]

Nous savons que :

\[ A^{-1} = \frac13 \begin{pmatrix} 2&-2&1\\ 9&3&-3\\ -8&-1&2 \end{pmatrix}. \] Ainsi :

\[ \begin{pmatrix} x\\y\\z \end{pmatrix} = \frac13 \begin{pmatrix} 2&-2&1\\ 9&3&-3\\ -8&-1&2 \end{pmatrix} \begin{pmatrix} 400\\1420\\2460 \end{pmatrix}. \]

Calcul de \(x\)

\[ x= \frac13 \left[ 2(400)-2(1420)+1(2460) \right]. \] \[ x= \frac13 (800-2840+2460). \] \[ x=\frac{420}{3}. \] \[ \boxed{x=140}. \]

Calcul de \(y\)

\[ y= \frac13 \left[ 9(400)+3(1420)-3(2460) \right]. \] \[ y= \frac13 (3600+4260-7380). \] \[ y=\frac{480}{3}. \] \[ \boxed{y=160}. \]

Calcul de \(z\)

\[ z= \frac13 \left[ -8(400)-1420+2(2460) \right]. \] \[ z= \frac13 (-3200-1420+4920). \] \[ z=\frac{300}{3}. \] \[ \boxed{z=100}. \]
\[ \boxed{(x,y,z)=(140,\;160,\;100)} \]

Vérification

Première équation :

\[ 140+160+100=400. \]

Deuxième équation :

\[ 2(140)+4(160)+5(100) =280+640+500 =1420. \]

Troisième équation :

\[ 5(140)+6(160)+8(100) =700+960+800 =2460. \]

Les trois équations sont donc vérifiées.

4. Application au problème de couture

On note :

\[ x=\text{nombre de pantalons }P_1, \] \[ y=\text{nombre de pantalons }P_2, \] \[ z=\text{nombre de pantalons }P_3. \]
Type \(P_1\) \(P_2\) \(P_3\)
Coût (DT) 8 16 20
Tissu (m) 1 1,2 1,6

a. Traduction de la situation par le système \((S)\)

1) Nombre total de pantalons :

L'atelier confectionne \(400\) pantalons :

\[ \boxed{x+y+z=400}. \]

2) Coût total :

Le coût total est de \(5680\) dinars :

\[ 8x+16y+20z=5680. \]

En divisant par \(4\) :

\[ \boxed{2x+4y+5z=1420}. \]

3) Longueur totale du tissu :

La longueur totale du tissu est de \(492\) mètres :

\[ x+1,2y+1,6z=492. \]

Pour supprimer les nombres décimaux, on multiplie toute l'équation par \(5\) :

\[ 5x+6y+8z=2460. \]

On obtient donc :

\[ \boxed{ \left\{ \begin{aligned} x+y+z&=400\\ 2x+4y+5z&=1420\\ 5x+6y+8z&=2460 \end{aligned} \right. } \]

C'est exactement le système \((S)\) étudié dans la question 3.

b. Déterminer le nombre de pantalons de chaque modèle

Nous avons déjà résolu le système :

\[ \boxed{x=140,\qquad y=160,\qquad z=100}. \]

Donc :

\[ \boxed{140\text{ pantalons du modèle }P_1} \] \[ \boxed{160\text{ pantalons du modèle }P_2} \] \[ \boxed{100\text{ pantalons du modèle }P_3}. \]

Vérification avec les données de l'atelier

Nombre total :

\[ 140+160+100=400. \]

Longueur du tissu :

\[ 140+1,2(160)+1,6(100) =140+192+160 =492. \]

Coût total :

\[ 8(140)+16(160)+20(100) =1120+2560+2000 =5680. \]

Les trois données de l'énoncé sont donc parfaitement respectées.

Réponse finale : \[ \boxed{ P_1=140,\qquad P_2=160,\qquad P_3=100 } \]
Attention à une erreur précédente : la valeur \((20,120,260)\) donnée précédemment était incorrecte. La vérification directe dans le système montre que la bonne solution est \[ \boxed{(140,160,100)}. \]
