Exercice — Test de la dérivée première

Une étude de fonction où la difficulté principale est de trouver les valeurs pour lesquelles la dérivée s'annule.

EXERCICE · FIRST DERIVATIVE TEST

Énoncé

On considère la fonction :

\[ \boxed{f(x)=\frac{x^4+1}{x^2+1}} \]

Déterminer les valeurs de \(x\) pour lesquelles la dérivée est nulle, puis utiliser le test de la dérivée première pour étudier les variations et les extrema de \(f\).

1. Où se trouve la difficulté ?

Le point délicat de l'exercice :

La dérivée est facile à calculer, mais sa résolution demande une étape supplémentaire : résoudre une équation du quatrième degré sous une forme factorisée.

Après dérivation, on obtient :

\[ f'(x)= \frac{2x(x^4+2x^2-1)}{(x^2+1)^2}. \]

Il faut donc résoudre : \[ x^4+2x^2-1=0. \]

Astuce :

On ne cherche pas directement une formule compliquée en \(x\). On pose \(X=x^2\). L'équation devient une équation du second degré :

\[ X^2+2X-1=0. \]

C'est cette transformation qui rend le problème accessible.

2. Objectif de l'étude

Nous allons suivre exactement la démarche utilisée dans les autres exercices :

  1. déterminer le domaine ;
  2. calculer la dérivée ;
  3. chercher les valeurs critiques ;
  4. étudier le signe de \(f'\) ;
  5. dresser le tableau de variations ;
  6. identifier les extrema.

3. Prérequis

À savoir avant de commencer :
  • résoudre une équation du second degré ;
  • connaître le signe d'un carré ;
  • savoir dériver un quotient ;
  • connaître le lien entre le signe de \(f'\) et les variations de \(f\).

4. Domaine de définition

Le dénominateur est \(x^2+1\). Or : \[ x^2\geq0 \quad\Longrightarrow\quad x^2+1>0 \] pour tout réel \(x\).

Donc : \[ \boxed{D_f=\mathbb{R}}. \]

5. Calcul de la dérivée

On utilise la formule de dérivation d'un quotient :

\[ \left(\frac{u}{v}\right)' = \frac{u'v-uv'}{v^2}. \]

Avec :

\[ u(x)=x^4+1,\qquad v(x)=x^2+1. \]

Donc :

\[ f'(x) = \frac{4x^3(x^2+1)-2x(x^4+1)} {(x^2+1)^2}. \]

On simplifie le numérateur :

\[ \begin{aligned} 4x^3(x^2+1)-2x(x^4+1) &=4x^5+4x^3-2x^5-2x\\ &=2x^5+4x^3-2x\\ &=2x(x^4+2x^2-1). \end{aligned} \]
Forme factorisée : \[ \boxed{ f'(x)= \frac{2x(x^4+2x^2-1)} {(x^2+1)^2} } \]

6. Valeurs pour lesquelles \(f'(x)=0\)

Comme \((x^2+1)^2>0\) pour tout \(x\), les zéros de \(f'\) sont donnés par : \[ 2x(x^4+2x^2-1)=0. \]

Donc :

\[ x=0 \quad\text{ou}\quad x^4+2x^2-1=0. \]

Résolution de \(x^4+2x^2-1=0\)

Posons :

\[ X=x^2. \]

On obtient :

\[ X^2+2X-1=0. \]

Le discriminant vaut :

\[ \Delta=2^2-4(1)(-1)=8. \]

Donc :

\[ X=\frac{-2\pm\sqrt8}{2} =-1\pm\sqrt2. \]

Comme \(X=x^2\geq0\), seule la valeur \[ X=-1+\sqrt2=\sqrt2-1 \] est acceptable.

Ainsi :

\[ x^2=\sqrt2-1 \] \[ \boxed{x=\pm\sqrt{\sqrt2-1}}. \]
Les trois valeurs critiques sont donc : \[ \boxed{ -\sqrt{\sqrt2-1},\quad 0,\quad \sqrt{\sqrt2-1} } \]

C'est précisément ici que se situe la difficulté signalée dans l'énoncé : il faut transformer une équation du quatrième degré en une équation du second degré.

7. Étude du signe de \(f'(x)\)

Posons : \[ a=\sqrt{\sqrt2-1}>0. \] Alors : \[ f'(x)= \frac{2x(x^2-a^2)(x^2+a^2)} {(x^2+1)^2}. \] Or : \[ x^2+a^2>0 \quad\text{et}\quad (x^2+1)^2>0. \]

Le signe de \(f'\) dépend donc seulement de \[ x(x^2-a^2)=x(x-a)(x+a). \]

\(x\) \(-\infty\)\(-a\)\(0\)\(a\)\(+\infty\)
\(f'(x)\) \(-\)0\(+\)0\(-\)0\(+\)
Lecture du signe :
  • sur \(]-\infty,-a[\), \(f'<0\) ;
  • sur \(]-a,0[\), \(f'>0\) ;
  • sur \(]0,a[\), \(f'<0\) ;
  • sur \(]a,+\infty[\), \(f'>0\).

8. Tableau de variations

Le test de la dérivée première donne directement les variations :

\(x\) \(-\infty\)\(-a\)\(0\)\(a\)\(+\infty\)
\(f'(x)\) \(-\)0\(+\)0\(-\)0\(+\)
\(f(x)\) \(+\infty\) ↘ \(2(\sqrt2-1)\) ↗ \(1\) ↘ \(2(\sqrt2-1)\) ↗ \(+\infty\)

On utilise ici le fait que : \[ f'<0\Rightarrow f\text{ décroît}, \qquad f'>0\Rightarrow f\text{ croît}. \]

9. Extrema

En \(x=-a\)

Le signe de \(f'\) passe de \(-\) à \(+\). La fonction passe donc de décroissante à croissante :

\[ \boxed{\text{minimum local en }x=-a}. \]

En \(x=0\)

Le signe de \(f'\) passe de \(+\) à \(-\). La fonction passe donc de croissante à décroissante :

\[ \boxed{\text{maximum local en }x=0}. \]

En \(x=a\)

Le signe de \(f'\) passe de \(-\) à \(+\) :

\[ \boxed{\text{minimum local en }x=a}. \]

Calcul des valeurs :

\[ f(0)=1 \] et, pour \(a^2=\sqrt2-1\), \[ f(a) = \frac{a^4+1}{a^2} = 2(\sqrt2-1). \] Donc les deux minima ont pour valeur :

\[ \boxed{2(\sqrt2-1)}. \]

10. Image de la fonction

Les deux minima ont la même valeur et la fonction tend vers \(+\infty\) aux deux extrémités.

Conclusion : \[ \boxed{ \operatorname{Im}(f)= [\,2(\sqrt2-1),+\infty[ } \]

11. À retenir

Test de la dérivée première :

Si \(f'\) change de signe :

  • \(-\) vers \(+\) : \(f\) admet un minimum local ;
  • \(+\) vers \(-\) : \(f\) admet un maximum local.
La difficulté de cet exercice :

Ce n'est pas le tableau de variations lui-même. La difficulté est de trouver correctement les zéros de \(f'\), ici en transformant \[ x^4+2x^2-1=0 \] en une équation du second degré grâce à \(X=x^2\).

Technologie :

Un logiciel de calcul symbolique peut aider à vérifier la dérivée et à résoudre l'équation. Mais la transformation \(X=x^2\) permet de comprendre mathématiquement pourquoi les valeurs \[ x=\pm\sqrt{\sqrt2-1} \] apparaissent.

💡 Pourquoi cet exercice est intéressant ?

L'énoncé attire l'attention sur la difficulté réelle du test de la dérivée première : trouver les valeurs où \(f'(x)=0\).

Ici, la dérivée conduit à une équation en \(x^4\). La substitution \(X=x^2\) transforme cette équation en une équation du second degré.

La technologie peut servir à vérifier le calcul, mais la correction montre la démarche mathématique complète.
